✗ Nguyên nhân:

  - Sau 1 tuần, file tạm bị xóa tự động bởi hệ thống

Chạy script tự động setup:

    cd /home/user/MauBieu7202
    ./setup_templates.sh

Hoặc setup thủ công:

    # 1. Migrate database
    python manage.py migrate

    # 2. Tạo folder lưu templates
    mkdir -p media/templates/docx

    # 3. Upload templates qua Admin
    python manage.py runserver 0.0.0.0:8000
    # → Truy cập: http://your-ip:8000/admin
    # → Templates > Add Template > Upload file .docx

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1️⃣  GIẢI PHÁP 1: Lưu vào Media Folder (KHUYÊN DÙNG)                         │
└─────────────────────────────────────────────────────────────────────────────┘

  ✅ Ưu điểm:
     • Template KHÔNG BAO GIỜ hết hạn
     • Ổn định nhất, không phụ thuộc folder bên ngoài
     • Quản lý qua Django Admin
     • Backup dễ dàng

  ❌ Nhược điểm:
     • Chiếm dung lượng server
     • Phải upload lại templates

  📝 Cách làm:
     ./setup_templates.sh
     → Chọn option 1


┌─────────────────────────────────────────────────────────────────────────────┐
│ 2️⃣  GIẢI PHÁP 2: Link tới Folder maubieumoi                                │
└─────────────────────────────────────────────────────────────────────────────┘

  ✅ Ưu điểm:
     • Không chiếm dung lượng server
     • Cập nhật template dễ (chỉ cần thay file)
     • Dùng chung với hệ thống khác

  ❌ Nhược điểm:
     • ⚠️ CRITICAL: Nếu mất kết nối folder → Hệ thống ngừng hoạt động
     • Performance chậm hơn (nếu folder qua mạng)

  📝 Cách làm:
     # Tạo folder maubieumoi
     mkdir -p /home/user/maubieumoi
     cp *.docx /home/user/maubieumoi/

     # Link
     ./setup_templates.sh
     → Chọn option 2

  ⚠️ Lưu ý:
     Nếu folder maubieumoi trên máy khác (network share):
     → Phải mount folder trước
     → Nếu network disconnect → Toàn bộ hệ thống lỗi
     → Nên dùng Giải pháp 3 thay vì


┌─────────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  GIẢI PHÁP 3: Hybrid - Kết hợp cả 2 (TỐT NHẤT)                          │
└─────────────────────────────────────────────────────────────────────────────┘

  ✅ Ưu điểm:
     • Kết hợp ưu điểm của cả 2 giải pháp trên
     • Ưu tiên đọc từ folder maubieumoi
     • Tự động fallback sang media/ nếu mất kết nối
     • Auto-cache để tăng performance

  ❌ Nhược điểm:
     • Phức tạp hơn trong setup

  📝 Cách làm:
     ./setup_templates.sh
     → Chọn option 3

  🔄 Cách hoạt động:
     User request template
         ↓
     1. Check folder /home/user/maubieumoi
         ↓
        [Có] → Load → Auto-cache vào media/ → Return
         ↓
        [Không] → Check media/ (cache)
         ↓
        [Có] → Load từ cache → Return
         ↓
        [Không] → Error

❓ File vẫn bị corrupt sau khi setup?
   → Template gốc đã bị corrupt
   → Chạy: python validate_templates.py /path/to/templates
   → Thay thế templates bị lỗi bằng file .docx mới

❓ Permission denied?
   → chmod -R 755 media/
   → chmod -R 755 /home/user/maubieumoi/

❓ Network share bị disconnect?
   → Check: mountpoint /mnt/maubieumoi
   → Remount: sudo mount -a
   → Hoặc dùng Giải pháp 3 để có fallback

❓ Template không hiển thị?
   → Kiểm tra: ls -la media/templates/docx/
   → Kiểm tra database: python manage.py shell
   → Restart server: python manage.py runserver
