🔧 CÁCH SỬ DỤNG CƠ BẢN:

   1. Đặt tất cả file .docx cần convert vào 1 folder (ví dụ: mau_bieu_cu/)

   2. Mở terminal/cmd tại folder chứa script

   3. Chạy lệnh:

      python convert_old_templates.py mau_bieu_cu/

   4. Nhấn Enter để xác nhận

   5. Script sẽ:
      ✓ Tự động backup file gốc
      ✓ Thay thế TẤT CẢ biến cũ → biến mới
      ✓ Báo cáo chi tiết những gì đã làm
