Hướng dẫn khởi động
Trên Windows:
cd kpi_dashboard
run_kpi_dashboard.bat

Hoặc double-click vào file run_kpi_dashboard.bat

Trên Linux/Mac:
cd kpi_dashboard
./run_kpi_dashboard.sh
Hoặc chạy trực tiếp với Streamlit:
cd kpi_dashboard
streamlit run app.py
Dashboard sẽ mở tại địa chỉ: http://localhost:8501
Cách sử dụng
  1. Chọn Tháng/Năm và Mã GDV tại sidebar
  2. Upload File KPI Mẫu (bắt buộc)
  3. Upload ít nhất một file: Thẻ, SMS, hoặc E-Mobile
  4. Nhấn "Phân tích & Xuất Báo cáo"
  5. Xem thống kê tổng hợp
  6. Tải xuống file Excel kết quả
