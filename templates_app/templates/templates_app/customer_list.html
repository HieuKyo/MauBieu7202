Hướng dẫn sử dụng:
  1. Copy dữ liệu từ hệ thống AGRIBANK (bao gồm cả header)
  2. Paste vào Notepad hoặc text editor
  3. Lưu file với extension .tsv hoặc .txt
  4. Chọn file và nhấn Import
Các trường được import:
  • Mã KH, Họ tên, CMND/CCCD
  • Ngày sinh, Giới tính
  • Số điện thoại, Email
  • Địa chỉ, Nghề nghiệp
  • Ngày cấp CCCD, Nơi cấp
Lưu ý:
  • File phải có encoding UTF-8
  • Phân cách bằng Tab
  • Ngày tháng format: YYYYMMDD
  • Nếu CMND đã tồn tại → Cập nhật
