Hướng dẫn sử dụng biến

Trong file Word template, bạn có thể sử dụng các biến sau:

  • {% templatetag openvariable %} ten_chi_nhanh {% templatetag closevariable %}
  • {% templatetag openvariable %} ten_chi_nhanh_hoa {% templatetag closevariable %}
  • {% templatetag openvariable %} mst {% templatetag closevariable %}
  • {% templatetag openvariable %} dia_chi_chi_nhanh {% templatetag closevariable %}
  • {% templatetag openvariable %} giao_dich_vien {% templatetag closevariable %}
  • {% templatetag openvariable %} kiem_soat_vien {% templatetag closevariable %}
  • {% templatetag openvariable %} giam_doc {% templatetag closevariable %}
Biến Ngày tháng năm:

Từ ngày sinh khách hàng:

  • {% templatetag openvariable %} d1 {% templatetag closevariable %}, {% templatetag openvariable %} d2 {% templatetag closevariable %} - Ngày (2 chữ số)
  • {% templatetag openvariable %} m1 {% templatetag closevariable %}, {% templatetag openvariable %} m2 {% templatetag closevariable %} - Tháng (2 chữ số)
  • {% templatetag openvariable %} y1 {% templatetag closevariable %}, {% templatetag openvariable %} y2 {% templatetag closevariable %}, {% templatetag openvariable %} y3 {% templatetag closevariable %}, {% templatetag openvariable %} y4 {% templatetag closevariable %} - Năm (4 chữ số)
Biến Khách hàng:

Tự động có khi chọn khách hàng:

  • {% templatetag openvariable %} ho_ten {% templatetag closevariable %}
  • {% templatetag openvariable %} so_cmnd {% templatetag closevariable %}
  • {% templatetag openvariable %} dia_chi {% templatetag closevariable %}
  • ... và các trường khác của khách hàng
Lưu ý: Các biến này tự động có sẵn trong mọi mẫu biểu, không cần cấu hình thêm.
