Tên file phải theo format: [USER_ID][DDMMYYYY].DBF
Ví dụ: GRATHIEU26092025.DBF nghĩa là:
- User ID: GRATHIEU
- Ngày: 26/09/2025

File DBF cần có các trường sau:
- ACCTCD: Số tài khoản
- TRDRCR: Loại giao dịch (D = Nợ, C = Có)
- REFNO: Số tham chiếu (để gom nhóm bút toán)
- TRAMT: Số tiền
- TRTIME: Thời gian giao dịch

Hệ thống sẽ:
1. Gom nhóm các bút toán Nợ/Có theo REFNO
2. So khớp với bảng quy tắc (hesoquydoi)
3. Nếu khớp, cộng điểm theo hệ số quy đổi
4. Tổng hợp điểm theo ngày và theo tháng
